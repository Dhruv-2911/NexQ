# Keyboard Shortcuts

On macOS, use `Cmd` wherever this page says `Ctrl` for the global shortcuts and for `Ctrl+F`.

## Global shortcuts

These work from any app, even when iA-ASR isn't focused. The keys below are the defaults; change any of them in **Settings > Hotkeys**.

| Shortcut | Action |
|---|---|
| `Ctrl+M` | Start a meeting, or end the running one. Starting this way skips the setup dialog and uses the audio mode you used last. |
| `Ctrl+B` | Show or hide the overlay. During a meeting it switches between the overlay and the dashboard; with no meeting running it brings the dashboard back. |
| `Ctrl+,` | Open or close Settings. |
| `Ctrl+Shift+H` | Turn **Hide from screen share** on or off. |

## During a meeting

These work while the overlay window is focused and you aren't typing in a text field.

| Shortcut | Action |
|---|---|
| `M` | Mute or unmute your microphone ("You"). |
| `Ctrl+Shift+L` | Open or close the Dev Log. Uses `Ctrl` on macOS too. |
| `Esc` | Close the Dev Log. |

## Reviewing a past meeting

| Shortcut | Action |
|---|---|
| `Ctrl+F` | Search the transcript. |

If the meeting was recorded, these control the player when no text field is focused:

| Shortcut | Action |
|---|---|
| `Space` | Play or pause. |
| `Left` / `Right` | Skip back or forward 5 seconds. |
| `Shift+Left` / `Shift+Right` | Skip back or forward 15 seconds. |
| `[` / `]` | Slower or faster playback (0.5x to 2x). |

## Settings

| Shortcut | Action |
|---|---|
| `Esc` | Close Settings. |

**Settings > Hotkeys** changes the global shortcuts. The new key works at once. The **Hide from screen share** shortcut can also be changed in **Settings > General**.

## System tray

iA-ASR keeps an icon in the system tray (the menu bar on macOS).

| Action | Result |
|---|---|
| Click the icon (Windows) | Brings iA-ASR back: the overlay during a meeting, otherwise the dashboard. |
| Middle-click the icon (Windows) | Mutes or unmutes your microphone during a meeting. |
| Right-click the icon (Windows), or click it (macOS) | Opens the menu. |

The menu opens the dashboard (**Open Dashboard**) or, during a meeting, the overlay (**Show Overlay**). It also starts or stops a meeting, mutes your microphone or the system audio during a meeting, hides the overlay window (**Hide Overlay**), turns **Hide from Screen Share** on or off, opens **Settings**, and quits (**Quit iA-ASR**).

With **Hide from screen share** on, iA-ASR has no taskbar button (Windows) or Dock icon (macOS), so the tray icon and `Ctrl+B` are the ways back to it.
